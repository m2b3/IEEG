# Shortcuts

## Navigation

### Time

- **Left Arrow**: move backward in time
- **Right Arrow**: move forward in time
- **Shift + Left Arrow**: move backward faster
- **Shift + Right Arrow**: move forward faster
- **Ctrl + Left Arrow**: move backward much faster
- **Ctrl + Right Arrow**: move forward much faster

### Channels

- **Mouse wheel in the signal area**: scroll through channels
- **Up Arrow**: move upward through channels
- **Down Arrow**: move downward through channels
- **Shift + Up Arrow**: move upward faster
- **Shift + Down Arrow**: move downward faster
- **Ctrl + Up Arrow**: move upward much faster
- **Ctrl + Down Arrow**: move downward much faster

### Visual Adjustments

- **Shift + mouse wheel in the signal area**: change time zoom
- **Shift + mouse wheel in the channel-label area**: change the visible channel count
- **Mouse wheel over the amplitude axis**: change amplitude scale

## Selection

- **Click a trace or channel label**: select one channel
- **Ctrl + click**: add or remove one channel from the selection
- **Shift + click**: select a range
- **Ctrl + Shift + click**: add a range to the current selection

## Modes

### Zoom Selection

- **Escape**: cancel zoom selection before applying it
- **Double left-click in the viewer**: go back one zoom step

### Scalogram Mode

- **Escape**: cancel scalogram mode before opening a scalogram

### Annotation Mode

- **Escape**: cancel annotation mode before placing an annotation

## Panels

- **Ctrl + T**: open the Power Spectrum panel
- **Double-click a dock title bar**: dock or undock the panel, depending on its current state
